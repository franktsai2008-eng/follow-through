Every deal leaves a tail that crosses a company line: confirm terms, chase delivery, chase payment. Follow-Through lets each company run that tail with its own agent in plain prose. A buyer agent (Claude) and a seller agent (GPT) hold a private card with a hidden constraint and a written authority limit, no manager to call. They exchange prose only, then each writes its own record, and a third model audits the exchange blind.

The stack is a stdlib Python server calling four outside partners. You.com Search API returns public price context, compressed to one line shown on both cards with its source domains. The blind audit also runs as a CrewAI crew, checked against a single-model judge on the same question. Daytona replays the scoring in a sandbox neither company controls, records only, no keys inside. One sends the follow-up email through Gmail once a person edits and approves, checked against a recipient allowlist.

After each case the seller writes itself one lesson (Learned) and reads prior lessons before the next case (Recalled). Across repeated cases it states its limit more often and stops overstepping, without refusing deals it can close. Rejecting a proposed action also writes a lesson.
