After a meeting, the follow-up often gets dropped or sent wrong, with no memory of what worked last time. Follow-Through takes the meeting notes, structures them, works out the follow-up strategy with the person in a short chat, drafts the email, and lets the person edit and send it. Every edit becomes a lesson it recalls next time.

The app is a Python server calling four outside services. The You.com Search API returns public context about the other company, shown with source domains on the digest. A CrewAI crew, a strategist and a skeptic, works out two or three follow-up strategies before the chat starts. One sends the final email through Gmail once the person presses Send, checked against a recipient allowlist, and stores each lesson with `one mem add`.

The learning loop is the point. Before a case starts, the app shows Recalled: lessons from earlier cases. After a case, it shows Learned: what this case taught it. Chat corrections, draft edits, and outright rejections all become lessons in `lessons.md` and in One's memory. Daytona replays the edit-ratio trend across all cases in a sandbox, records only, no keys inside, to check whether the person edits less over time.
